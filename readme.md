# Sobre o que é este projeto?

Esse é o meu portfólio pessoal, criado para reunir um pouco sobre mim, minha experiência profissional, currículo e formas de contato.

A ideia foi fugir de um portfólio tradicional e criar algo mais divertido e interativo, inspirado no visual clássico do Windows 95. O site funciona como uma pequena área de trabalho retrô, onde você pode explorar atalhos, abrir janelas e descobrir mais sobre mim.

Ao entrar, você passa por uma tela de inicialização personalizada e, depois, pode navegar pela área de trabalho, acessar meu currículo, minhas redes e até interagir com o Rover, o assistente da interface.

# Tecnologias utilizadas
* React
* Vite
* React95 - utilizado para trazer a estética clássica do Windows 95
* Tailwind CSS
* ESLint
